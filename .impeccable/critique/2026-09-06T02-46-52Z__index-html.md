## Design Specificity Verdict

LLM assessment: Authored for this family, not a reskinned template - Linhagens computed live from real surname tokens, pull-quote is a real specific story, stats reflect a real small archive. Hero's opening frame (tight eye/face crop) is the one generic-feeling moment until copy anchors it.

Deterministic scan: 3 HTML findings (hero-eyebrow-chip, flat-type-hierarchy, codex-grid-background false positive) + 15 live browser findings, mostly undersized text (brand at 8.55px, nav items at 10px) - direct result of this session's explicit font-size reduction requests.

False positive: codex-grid-background attributed to index.html but the underlying CSS rule (.tree-main dot background) targets the Arvore page; tree-main class does not exist in index.html.

## Overall Impression

Real, consistent visual identity, not a template. Main problem is structural: the Linhagens section is the first thing after the Hero and has no heading at all, which coincides exactly with an independently-found technical issue (heading order skips h2 entirely).

## What's Working

- Linhagens computed from real data (computeLinhagens/surnameTokens), not hardcoded
- Cohesive design-token system across hero, cards, buttons, stats, quote
- Empty-state already handled for Linhagens (shows the gap elsewhere is an oversight, not a philosophy)

## Priority Issues

[P1] Header brand + nav text below legibility floor - "Olsen . Belloto . Leal" at 8.55px, nav items at 10px, confirmed live by the injected detector. Site-wide, hits the older-relative persona hardest. Fix: reconsider these two specific pieces back toward 11-12px since they're functional (navigational) text. Suggested command: typeset

[P1] Linhagens section has no heading, dumps 6 items right after the Hero - no .section-head/h2, unlike Comece por aqui below it; this is exactly the root cause of the detector's skipped-heading finding (h1 -> h3, no h2). "Olsen" itself shows only 1 pessoa, reading as broken data. Fix: add h2 + one-line explainer, cap visible cards at 4. Suggested command: clarify

[P1] "0 fontes citadas" has no fallback, contradicts the Hero's own pitch about sources - anosCobertos has ||'-', sources.length does not. Distinct from the count-up animation's transient 0 state that Assessment B separately observed. Fix: apply the same ||'-' treatment to sources.length. Suggested command: harden

[P2] No loading state for async-populated sections - Linhagens/Portas/Numeros/Quote empty until Promise.all resolves, no skeleton. Fix: skeleton placeholders. Suggested command: polish

[P2] Linhagem cards have almost no clickable affordance - thin gold rule over plain text vs porta-card's full frame. Fix: visible hover/focus treatment. Suggested command: clarify

## Persona Red Flags

Jordan (first-timer): lands on unlabeled Linhagens grid, no idea what it means; sees "Olsen - 1 pessoa" (site's own namesake) and may conclude the archive is broken; hits the Joao Leal pull-quote with zero context.

Casey (distracted mobile): must scroll through a full 280vh sticky-pinned hero before reaching other content; linhagem-cards' near-invisible affordance means a quick scan may miss they're tappable.

Project-specific - older relative unfamiliar with modern web UI: word-by-word text reveal and mouse-tilt cards could read as a slow/broken page; small uppercase letter-spaced labels (11-13px, now 8.55-10px in header) are a known readability obstacle for presbyopia.
